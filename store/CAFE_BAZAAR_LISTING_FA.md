# Terminal SSH — متن آماده صفحه بازار

## نام
Terminal SSH

## توضیح کوتاه
ترمینال SSH امن و سبک برای اتصال مستقیم به سرورهای شما.

## توضیح کامل
Terminal SSH یک کلاینت SSH سبک برای Android است که ترمینال واقعی VT100/ANSI را روی اتصال SSH ارائه می‌کند. اثر انگشت Host Key در اولین اتصال نمایش داده می‌شود و تغییر کلید شناخته‌شده بدون تأیید نادیده گرفته نمی‌شود.

اطلاعات حساس با Android Keystore و AES-GCM روی دستگاه محافظت می‌شوند. ترافیک cleartext، backup داده‌های داخلی و اسکرین‌شات معمول صفحه ترمینال غیرفعال شده‌اند. برنامه تبلیغات، تحلیل‌گر رفتار یا حساب ابری ندارد.

ویژگی‌های نسخه 0.1.0: اتصال SSH با رمز عبور، ترمینال xterm-256color، تأیید Host Key در اولین اتصال، تشخیص تغییر Host Key، Clipboard و resize ترمینال، و Vault رمزنگاری‌شده روی دستگاه.
